# 早期数据副本（已停止更新）

本目录下的 `Box_Id.json` 是项目早期的开源数据快照，**只有 85 盒**，
比仓库根目录的 `Box_Id.json` 少 9 盒（`53.0`、`54.0`、`55.0`、`月行水上`、
`嘉年华2026`、`布道人`、`渡星客`、`戏中身`、`失语者`）。

## 请勿使用

- **新项目**请使用根目录的 [`Box_Id.json`](../Box_Id.json)；
- 列表页只需要索引的话，请用 [`Box_Index.json`](../Box_Index.json)（约 10 KB）；
- 本目录保留的原因：历史链接仍被外部项目引用
  （如 `ArknightsAuthenticationAssistant` 的 `resource/Box_Id.json`），
  直接删除会让那些页面 404。

## 如果要继续维护

不建议在这里补数据 —— 会形成两份互相漂移的同名文件。
正确的做法是把新数据合并进根目录，然后删掉本目录并同步修改外部引用。
